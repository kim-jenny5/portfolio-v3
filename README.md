# Portfolio v3

Welcome to my personal portfolio! 🌷

Built from scratch because I can and because I'd rather spend a weekend coding than pay a monthly subscription for Framer or Squarespace, etc.

## Tech Stack

- **Framework** — [Next.js 16](https://nextjs.org/) (App Router) with React 19
- **CMS** — [Sanity v5](https://www.sanity.io/) with embedded Studio, live visual editing, and draft mode preview
- **Styling** — [Tailwind CSS v4](https://tailwindcss.com/) with `tw-animate-css` for animations
- **Icons** — [Phosphor Icons](https://phosphoricons.com/)
- **Media** — [Vercel Blob](https://vercel.com/docs/storage/vercel-blob) for asset storage, `@sanity/image-url` for image transforms
- **Language** — TypeScript
- **Package manager** — pnpm
- **Deployment** — Vercel
